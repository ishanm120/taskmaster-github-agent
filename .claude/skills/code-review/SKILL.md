# Code Review Skill

Check Correctness, Security, Error Handling, Test Coverage, Code Clarity, DRY and Dependency Safety. Distinguish HIGH (blocks), MEDIUM (should address), LOW (optional). Cite file/line or concrete evidence, avoid speculative findings. Mark each FR/NFR COVERED or NOT_COVERED with evidence.
